# 修正 IR(中间表示)schema · v0.2

一张带批注的线稿,解读产物为一个 JSON 对象。这是 worker 的核心输出契约,
任何 VLM 后端都必须产出同构结果。

## 顶层

```json
{
  "sheet": "文件名",
  "corrections": [ Correction, ... ],
  "trace_marks": [ TraceMark, ... ],
  "meta_notes": [ "赛璐璐编号/问候/流程文字", ... ]
}
```

## 三类系统(必须先分清,再解读)

| 系统 | 是什么 | 处置 |
|---|---|---|
| 色トレス分色线 | 画本身的一部分(给上色部门):水色=影指定、红贴形细线=高光指定、黄绿/翠绿=其他分色、绿填涂=BL填黑 | **保留**,不产生编辑指令 → `trace_marks` |
| 修正指示 | 作监/演出给原画师的指令:潦草示意笔触、圈、X、引出线、重绘形、手写文字 | 解读 → `corrections` |
| 生产元数据 | 赛璐璐编号(Aの3)、问候语、口型表、流程指令 | 记录 → `meta_notes`,不产生编辑指令 |

同色异义(红既是高光分色线又是修正传统色)的判别线索:
**贴形精确 vs 潦草示意;画内随形 vs 画外留白/跨形;有无文字/圈/引出线配套。**

## Correction 对象

```json
{
  "id": "slug",
  "color": "red|green|orange|pencil|...",
  "location": "指向画面何处(自然语言,要落到具体物体:'左角根部的双环耳环',不是'左上方')",
  "transcription": "日文原文(纯笔触则空)",
  "translation": "中文/英文译文",
  "type": "replace|displace|indicate|constrain|annotate|delete|meta",
  "actionable": true,
  "edit_instruction": "给图像编辑器的单句祈使指令,必须绑定到具体画面对象"
}
```

`type` 六分类沿用研究计划书 §4.5:
replace 直接画出正确形态 / displace 指示移动方向幅度 / indicate 仅圈出区域 /
constrain 规定须满足的条件(部分规范,RQ2 核心) / annotate 文字补充 / delete 标示多余。

`actionable=false` 的情形:指令面向流程或其他部门(口型省略、树种标注)、
指向外部参考(「噴水は演修を参考に」)、或 constrain 无法落成单句编辑指令时如实标注。

## Correction 增补字段(v0.3)

`scope`: `"sheet"`(改本张) | `"cut"`(跨张一致性,面向该镜其他赛璐璐) | `"process"`(流程)。
依据:修正稿常是**两版叠加**(原稿 rough × 修正版 clean,以线色区分层),批注可指向
"其他张按修正版对齐"——不识别 scope 会把跨张指令误执行在本张上。

## 首轮实验已证实的失败模式(worker 判据要防)

1. **端到端把批注当噪声**:不给显式指令时,执行模型把修正擦干净、原样保留被修正物(实验A:画X的耳环被重新描干净)。
2. **弱解读产出无绑定指令**:「删掉左角上的两条线」──没绑定到"耳环"这个对象,执行端无法落地(实验B, gpt-4o)。
   ⇒ `edit_instruction` 的合格判据:**指令里必须出现目标对象的名词**,不允许只有方位词。
3. **图层语义误读(连巫师都会犯)**:hair_flow 稿上蓝线=修正版线稿(单笔 clean 轮廓)、黑线=原稿
   rough,「なびき合わせて」=各张按修正版对齐(scope=cut);v1 金标准把它误读成"本张内发丝
   方向统一"(scope=sheet),执行了一次画面上没被要求的改动。用户指正后 v2 修正(实验D)。
   ⇒ 解读第一步必须先判**本张是单版还是多版叠加**,再判每条批注的 scope。
4. **样板文压过指令(2026-09-02,用户发现)**:execute 模板硬编码"PRESERVE light-blue
   color-trace lines",与 gold IR"采纳蓝线丢弃黑 rough"直接冲突 → 模型服从样板文,
   合并**静默不执行**(校验全绿)。对照:无该条款的手写 prompt 同指令执行成功。
   ⇒ 律:**样板文只能断言 IR 没有话语权的部分;IR 可推翻的语义必须由 IR 供值**
   (`sheet_layers` 字段 → `_layer_rules()` 动态生成保护条款)。
5. **缺显式收敛目标**:修掉冲突后合并仍只走半程(黑 rough 清了,蓝线还是蓝色)——
   指令说"按蓝线版重画"但没说**画成什么**。补"AS CLEAN BLACK LINES / 最终必须是
   单版黑线稿"后表面收敛。⇒ 变换类指令必须写明**终态形态**,只写来源不写目标=半执行。
6. **表面服从(2026-09-02,用户发现;比 4/5 更深一层)**:修完 4/5 后成图满足指令的
   **视觉签名**(蓝线消失、单一版本、部分蓝线被变色成暗橙残迹)但**几何内容未执行**——
   肩线离黑线 17.3px、离蓝线 18.9px,谁都没跟,自画折中线。我上一轮"完全执行"判定
   即假阳性:判据(蓝线消失+单版)恰好就是视觉签名本身。
   ⇒ **merge/replace 类指令的执行证据必须是几何量化比对**(输出轮廓 vs 目标图层轮廓,
   判据=显著贴近目标层,src/verify_geometry.py;✗分支已反向验证,✓分支尚无真阳性样本)。
   ⇒ 工程推论:"采纳B版几何"很可能超出 raster edit 通道的可靠能力(RQ3 硬发现候选);
   merge 类修正的正路是**确定性图像处理**(蓝→黑变色+邻近被取代黑线剔除),生成模型只兜缝合。
7. **全图 edit 连"缝合"都不许做(2026-09-02)**:确定性合并已把几何锁在蓝线版(0.0px),
   只让生成模型"补小豁口+删耳环",肩线仍被拉回原稿侧(裁框控扣取景后 12px vs 24px,
   输入本身 0.0px ⇒ 破坏发生在这一步)。全图 edit=整图重合成,几何跟模型先验走。
   ⇒ **生成模型触碰承载几何的画面,只允许 masked inpaint(外科)**:mask 内改、mask 外保,
   实测耳环删除后几何 0.6px。= scrub 律的图像版。
   ⇒ 落地:混合管线 src/hybrid_pipeline.py(几何→代码/删除→裁片编辑贴回/批注→代码),
   三道几何闸全绿(0.4px),端到端可复现。
8. **闸不看的地方就是下一个事故点(2026-09-02,用户连抓两次)**:
   a) 复现跑覆盖了已人工验过的好卷,新卷 mask 区成黑块+全图黑线发灰——几何闸只量肩段,
      两者都不在覆盖内;我凭"闸绿"报了"已验证"。⇒ 已接受卷=固化资产(判据过即冻结复用);
      每次重跑后**必须重新审图**,闸绿≠图好。
   b) API mask edit 系统性不可靠:透明洞被原样画成黑块(4/5 卷),mask 外整幅重编码。
      ⇒ 外科唯一可靠通道=**裁片编辑+像素级贴回**(片外 assert 字节不变,恒真判据已反向设计)。
   c) 绿纸上"通道极差>45"判纸为墨,保护分支静默跳过=批注清除整步没生效。
      ⇒ 判据必须相对**就地采样的纸色基准**;异常占比 assert 报错,不许静默跳过。
9. **合并的两轮误伤史(2026-09-02,用户抓灰痕引出)**:
   a) 只删深色芯 ⇒ 抗锯齿灰晕存活,旧线以"被橡皮擦过"的灰痕留在纸上;
   b) 改"R内一切灰性墨迹"一刀切 ⇒ 恰好靠近蓝线的**正式画**被蚕食(眼睛被抹空);
   c) v3 结构性判据(删芯+自身晕)仍漏通体浅灰/蓝灰色调的轻笔画(用户第三次抓到灰痕);
      **v4 定稿=加法重建**:纯纸色画布上只落保留墨迹(保留线/彩色trace/保护区整块搬运/
      蓝转正式线)+连通域去噪(<6px 碎点,纯色画布会让 JPEG 噪斑显形)——被删的线在
      构造上不可能留残迹,减法路的阈值追逐就此终结;
      且**蓝点缀≠重绘线**(眼睑蓝色小笔触会误触发半径删除)⇒ merge 必须带 protect 区
      (面部中心),区域与 bbox 同源,worker 化后由 IR 供给。
   d) 固化缓存必须按**输入指纹**失效(_patch_in.sha1):旧底图的裁片贴新底图=旧缺陷回流。
10. **断线修补的分工与判据(2026-09-02,用户拍板)**:加法重建必然留断口(被删旧线与
    保留线交叉处)——接线交给模型,但只经外科通道(裁片+贴回),判据三件套:
    a) 原墨≥95%保留(**2px 容差**:逐像素精确重合会把亚像素漂移的好卷误拒,实测 4/6 误拒
       →容差后 6/6 过;真重画漂移>2px 仍拒得住);
    b) 新增墨≤60% + 纯纸面框跳过(不给模型画蛇添足的机会);
    c) 断口端点所属连通域≥40px —— 虚线装饰框的短段天然成对"断口",不滤会把修补框
       引到纸面上(实撞:1380 个断口滤后剩 22 个真断口);贴回必须配平+羽化(裸贴留色调矩形)。
