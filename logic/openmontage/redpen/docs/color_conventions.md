# 日本动画线稿用色规范参考(色トレス指定 × 修正指示)

> 调研日期:2026-09-01(web 调研 agent 完成,来源与可靠度逐条标注)。
> 行业**没有统一强制标准**,以下为惯例整理。多位从业者明确表示"色的用法因工作室、
> 因人而异,并无硬性规定"(Yahoo!知恵袋业内回答 q14229000434 / q14161801789)。
> ⇒ 工程含义:**判读器不可写死颜色表,须按"载体+形态+文字配套"综合判别,颜色只作先验。**

## 一、色トレス/分色线体系(画面本体的一部分,面向仕上げ部门)

### 基本概念
- **実線**:黑铅笔主线(成片上呈黑/深色)。**色トレス線**:彩铅线,表示"塗り分け边界
  但成片上不留黑线"——高光/阴影边界、白眼球分界、水面、光效轮廓等。
  (pixiv百科·色トレス;note·佐藤雅子〔吉卜力出身演出〕n29c3fd375393)
- 起源:赛璐珞时代描线机只感光黑线,彩线由仕上げ手工处理;数码化后惯例保留。
- 仕上げ时実線转黑、色トレス線转为邻色系,**成片基本不可见**。
- ⚠ 数码插画圈的"色トレス"(线画改色融入涂色)是派生的另一含义,勿混淆。

### 各色标准含义(通行惯例)

| 颜色 | 含义 | 备注 |
|---|---|---|
| 黑(铅笔) | 実線主线 | 数码规定纯黑 RGB(0,0,0) |
| 水色/蓝 | **影指定**(常再涂水色标影面) | 亦称1号影 |
| 红 | **ハイライト指定**(高光面常涂黄) | |
| 粉红 | 2号影常用色 | 因人而异 |
| 绿(填涂) | **BL(黑ベタ)指定**:涂绿=填纯黑 | BL=Black |
| 黄绿 | 其他色トレス:发丝渐变/瞳内/纹样分色 | |
| 橙/粉(硬质) | 色数不够时的补充 | 可靠度中 |

整套“高光=红线+黄涂、影=蓝线+水色涂、BL=绿涂”见玄光社·「仕上げ」の具体的な手順(可靠度高)。

### 实务限制
2值化扫描分离彩线:深绿/深蓝/紫易误判为黑,红与黑区分度最好;可判别色≈红、蓝、桃、紫、赤茶、橙、黄绿(AniLaSoft 官方手册,可靠度高)。

### 数码图层惯例
- CLIP STUDIO:主线层纯黑;色トレス按纯红(255,0,0)/纯绿/纯蓝分层;**批注文字与色トレス必须分层**否则会被照描进成片(note·George_blknt,仕上げ从业者)。
- Stylos:内建実線/色トレス层,修正レイヤー对应纸时代叠修正纸(millepensee 博客)。

## 二、修正指示体系(检查者批注,面向原画师)

### 工作方式:叠纸
修正不直接改原画,画在**叠加的修正用纸**上;检查链 LO→演出→作監→総作監。
早期惯例:动画纸下端红马克笔记号区分"原画/作监修正"(animator276,原从业者)。

### 各级修正的用色(⭐颜色载于**纸色**,非笔色)

| 检查者 | 常见纸色 | 可靠度 |
|---|---|---|
| 演出/監督 | 淡粉~红系纸(社差大) | 中高(Sakuga Wiki+animator276 互证) |
| 作画監督 | **黄纸**("色はほぼ黄色"/"usually yellow paper") | 高(日英两源一致) |
| 総作画監督 | 绿纸或深黄纸;日方称"色は様々" | 中(绿纸实例:Orb第16话総作監修正) |

- "作監修正=红铅笔"系坊间说法,**直接公开出处未找到,存疑**;旁证:红是扫描安全色+早期红记号惯例。现代主流=彩色纸+任意笔,笔色无统一规格。
- 数码化后:修正为**独立图层**,显示色(レイヤーカラー)代替纸色,导出不进成片。

## 三、两套体系的区分判据(按硬度排序)

1. **载体**(最硬,有来源):色トレス画在原画纸/画稿层上;修正在叠加修正纸/修正层上。
   ⇒ 对已合并成 JPG 的公开稿,载体信息丢失,只能退用 2-4。
2. **形态**(经验推断):色トレス是**闭合边界段**——两端接実線、围出可填色区、常配同色涂面;
   修正是**成形的重画**或圈划+箭头+X,不构成塗り分け闭区。
3. **文字配套**:修正常伴指令性文字;色トレス側文字是色指定术语(2号カゲ/BL/ハイライト)。
4. **颜色语义轴**:修正的颜色在纸色(粉/黄/绿=谁改的),色トレス的颜色在线色(红/蓝/绿=涂什么);
   "绿"两边都出现,靠载体/形态区分。

### 对本语料(MADHOUSE 芙莉莲公开稿)的适用注记
公开稿是合并后的单张 JPG(纸色→统一底色,载体线索丢失)。实际观察:
绿底/黄底两种纸色并存,同页可见"贴形精细彩线(trace)"与"潦草示意/圈/X/文字(修正)"。
判读器以形态+文字配套为主判据,颜色只作弱先验;歧义必须如实标 ambiguous。
