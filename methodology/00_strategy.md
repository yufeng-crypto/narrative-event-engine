# Stage 0 · 投资策略基线

> 这份文档是后面所有筛选规则、阈值、评分维度的"宪法"。规则有歧义时，回到这里看根。

## 投资人画像

- **47 岁，距 60 岁退休 13 年**
- **可投资金 400 万 RMB**（已扣除 105 万保险备用金）
- **不能动本金**（13 年后本金能保住即可，不要求增长）
- **持续现金流**：每年税后分红覆盖日常消费（目标 4-5%/年，约 16-20 万）
- 家庭已有保险打底（200 万额度 60 岁后接力），所以这 400 万**可以承担一定波动**，只要长期分红稳定

## 投资目标（量化）

| 指标 | 目标值 | 原因 |
| --- | --- | --- |
| 年化分红/分派率 | ≥ 4.5%（税后） | 国债 1.77% + 风险溢价 250-300bp = 投资人能接受的"风险补偿足够"门槛 |
| 13 年累计本金回撤上限 | ≤ 30%（账面）| 红利策略累计 13 年分红 ≈ 60% 本金，足以覆盖 30% 回撤还盈利 |
| 现金流确定性 | 单年分红波动 ≤ 30% | 避免某年突然减半导致生活费断流 |
| 流动性 | 单只持仓 ≤ 30 万元，可在 5 个交易日内清仓 80% | REITs 流动性偏弱，需要分散 |
| 行业分散 | 不超过 30% 暴露在单一行业 | 单板块系统性风险（如商业地产） |

## 三层资金配置（来自 Gemini 推演 + Opus 复核）

```
400w 流动资金
├── 保险缓冲层 105w（短债/大额存单/货基）→ 不在本监控池范围
├── 红利收租层 200w（A 股 + 港股红利 ETF）→ Pool 主体
└── REITs 增强层 95w（消费/保租房/能源/交通/物流 全分支）→ Pool 主体
```

监控池只关注后两层，第一层是手工管理。

## 关键风险约束

1. **不允许的资产类型**：单一股票、可转债、衍生品、加密货币、未上市股权
2. **不允许的标的特征**：
   - 上市不足 1 年（没有完整年度财报和分红记录）
   - 连续 2 年未分红（说明分红能力存疑）
   - 当前面临退市/清算风险
   - 底层资产单一项目（如单一商场、单一物业）且无扩募预期
3. **谨慎对待**：
   - 商业地产 REITs 受房地产周期影响（虽然不直接，但情绪传导）
   - 港股 QDII 有汇率风险
   - 海外标的（标普500 等）抗通胀但不分红

## 决策时序

1. **建仓**：信号触发后分 3-6 个月分批入场，避免一次买在高位
2. **持有**：长期持有（≥ 5 年）才能享受 A 股 1 年免红利税
3. **再平衡**：每年一次，单只持仓涨幅超 50% 或权重超过 35% 时主动平衡
4. **退出**：分派率连续 2 年下跌 > 20%、底层资产质量恶化、政策环境根本改变 → 清仓

## 这套策略的隐含假设

1. **A 股长期红利策略有 alpha**：基于学术界共识 + 国内 10 年回测数据
2. **REITs 监管框架稳定**：2024 年规则已基本成型，未来变化不剧烈
3. **国债利率长期处于低位**：风险溢价持续高于 250bp
4. **人民币汇率不出现大幅贬值**：所以可以以人民币计价资产为主

**这些假设任何一条被打破，需要重审策略**。监控池筛选不能解决这些根本风险。
